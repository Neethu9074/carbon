# Default Theme

Use this module to get the default theme's variables in your stylesheets:

```css
@import "~instana-ui-default-theme/less/variables.less";
```

Alternatively, use it as an ES6 module for styles that are applied via JavaScript:

```javascript
import theme from 'instana-ui-default-theme';

// theme.common.fontFamily
// theme.common.fontColor
```

The JavaScript file is build from the LESS file. To update the JavaScript file, simply run `npm run build`.

## Adding New Variables
Add variables in the `less/variables.less` file. Make sure to stick to the following rules:

 - Structure related variables using two underscores, e.g. `@common__font-size` and `@common__font-family`.
 - Use spinal case, e.g. `@solid-blue` instead of `@solidBlue`.
 - Use the color's name as its variable name. You can find out an approximate name for a color using [Name That Color](http://chir.ag/projects/name-that-color/#6195ED).

**Remember: Do not update the JavaScript files. These files are automatically generated by `npm run build`!**

## Development
It is easy to forget to update the JS file. We can obviously automate this! One simple way is a commit hook. To install the hook, run `npm run installHook`!
