# Default Theme

Use this module to get the default theme's variables in your stylesheets:

```css
@import "~instana-ui-themes/less/constants.less";
```

Alternatively, use it as an ES6 module for styles that are applied via JavaScript:

```javascript
import themes from 'instana-ui-themes';

// themes.consts.night.common.fontFamily
// themes.consts.night.common.fontColor
```

The LESS file is build from the JavaScript file. To update the LESS file, simply run `npm run build`.

## Adding New Constants
Add consts in the `js/index.js` file. Make sure to stick to the following rules:

 - Structure related variables using nested objects.
 - Use camel case for in keys, e.g. `fontFamily` instead of `font-family`.
 - Use a semantic name for color, i.e describe what the color is used for.

**Remember: Do not update the LESS file `less/constants.less`. This file is automatically generated by `npm run build`!**

## Development
It is easy to forget to update the LESS file. We can obviously automate this! One simple way is a commit hook. To install the hook, run `npm run installHook`!
