## Auto-Focussing Custom Elements

Use the `autoFocus` hook to automatically focus custom interactive elements which do not have browser-native
support for automatic focussing.

## Import

```js
import useAutoFocus from 'in-hooks/useAutoFocus';

// You will almost certainly need this as well!
import { toInteractiveElement } from 'in-new-components/interactiveCustomElement';
```

## Best-Practice Usage

```js
import React from 'react';

import { toInteractiveElement } from 'in-new-components/interactiveCustomElement';
import useAutoFocus from 'in-hooks/useAutoFocus';

function MyComponent() {
  const refContainer = useAutoFocus();

  return (
    <div
      ref={refContainer}
      {...toInteractiveElement({
        onDefaultInteraction: () => console.log('hey!'),
        ariaLabel: 'Do Something!'
      })}>
      My custom interactive element with autoFocus support!
    </div>
  );
}
```
