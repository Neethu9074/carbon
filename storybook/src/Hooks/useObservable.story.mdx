## Working With Observables

You can use the `useObservable` hook to subscribe to observables and their updates. Whenever an observables updates
its value (**by default only on pure changes**) the components' state is changed and the component is re-rendered.

Please note that synchronous availability of bound values cannot be guaranteed by this hook. We attempt to make
the last emitted value available within the first render, but this is not always possible (for example when an existing
subscription did not exist yet). **Your component must not rely on immediate availability of observables' values!**

## Import

```js
import useObservable from 'in-hooks/useObservable';
```

## Best-Practice Usage

```js
import React from 'react';

import { getSnapshot } from 'in-stores/snapshot/snapshot;
import useObservable from 'in-hooks/useObservable';

function MyComponent({snapshotId}) {
  const snapshot = useObservable(getSnapshotObservable, [snapshotId]);
  return (
    …
  );
}

function getSnapshotObservable([snapshotId]) {
  return getSnapshot(snapshotId)
}
```

## API

1.  The first parameter is a function, which useObservable will call to get an observable. It can be falsely to implement
    optional subscriptions, e.g. `useObservable(snapshotId && getSnapshotObservalbe, [snapshotId])` or `function getSnapshotObservable([snapshotId]) { return snapshotId && getSnapshot(snapshotId) }`.
2.  The external values used in the creation of the observable. This is required in order to understand when
    re-subscriptions are necessary or not. **Defining wrong/missing some values here can result in too frequent
    re-subscriptions or stale subscriptions being used**. The array defined in this step is passed to call the method given in step 1.
3.  An optional object to configure the subscription. At the moment it is only possible to configure whether the
    subscriptions' values are pure or not (defaulting to pure).
