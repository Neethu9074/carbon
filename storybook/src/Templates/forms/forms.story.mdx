## Goal 2: Simplify Form generation and usage without all the onChange mangling

Currently we have to be careful to always update the form as the state object,
so we need use the `onChange`, `updateIn`, `setForm` method.

This should be simplified, e.g. like:

```js
import React from 'react';

function MyComponent({initialForm}) {

  const { form, setForm } = useState(initialForm); // as usual

  return (
    <InjectForm form={form} setFrom={setForm}>

      <FormInputField fieldName="name" />
      <FormInputField fieldName="surName" />
      <FormInputField fieldName="age" type="number" />
      <FormDropDown fieldName="haveChildren" items={['yes', 'no',
              'many' ]} />

      <h2> Address Form </h2>

      <InjectForm fieldName="address" autoHide>

        <FormInputField fieldName="street" />
        <FormInputField fieldName="city" />

      </InjectForm>

      <AccessingFormSaveButton />

    </InjectForm>
  );
}
```

If there is no address in the form model, we can completely hide the address, right!


Accessing the form state inside any component:

```js
import React from 'react';

function AccessingFormSaveButton() {
  const { form } = useFormContext();

  return (
    <SaveButton
      enabled={form.hierarchyValid}/>
    );
}
```
