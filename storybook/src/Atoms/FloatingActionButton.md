# Summary

We use the Floating Action Button for primary actions that apply to a page / entity. A good example is “Create SLI” or “Add Alert”.

# Placement

## Floating Action Button Placement

- Floating Action Buttons are aligned to the bottom right with a 24 dp margin from the viewport boundaries
- Any scrollable content needs an additional 96 dp padding at the bottom to allow scrolling past the floating action button
