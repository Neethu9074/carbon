## Buttons

Buttons are a clickable (or tappable) action control which performs a single action when used. The action is performed on `mouse up` and can be canceled by dragging off the button after a `mouse down` event.

Buttons can optionally display a tooltip when hovered to display additional information or context.

## Button Kinds

**Colour**

Buttons have colours to add context - they should still be usable without colour (some users have colour blindness), but the colour should be used to enhance the information conveyed to the user - not the source of all information.

**Primary**
Green - the primary action on a page, there should only be 1 on a view

**PrimaryV2**
Blue - the primary action on a page, there should only be 1 on a view

**Secondary**
Grey - there can be many secondary actions on a view

**Secondary Darker**
Darker Grey - there can be many secondary actions on a view which a grey background

**Action**
A subtle action button

**Subtle**
A more subtle button with no outline

**Create**
A green action button to create an entity

**Danger**
A ref action button to delete, remove or destroy an entity


**Warning**
An orange button which may have important or unsafe actions associated

**Info**
A dark grey button which may be used for help, support or further information about the view

**Fixed Inline**
This buttons has a fixed width and height and is used for hover actions on for example table rows.



### Hover states

Buttons have a hover state which darkens the background colour to give visual feedback to the user that this component can be interacted with.
