### Atomic Design
Our component library follows the principles of [Atomic Design by Brad Frost](https://bradfrost.com/blog/post/atomic-web-design/) to learn more about Atomic Design you can also read this [blog post](https://medium.muz.li/atomic-design-methodology-166261ce47c2) going more in depth with the terminology.

### Project Goals
The goals of this project is not only to create an environment where we can build and test new components before implementing them in our UI. But it also to create a space where developers and designers can collaborate and expand on our components and design patterns and hopefully this will evolve into a design system.
