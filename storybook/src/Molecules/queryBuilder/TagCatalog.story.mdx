# Tag Catalog

In order to work the query builder requires access to a set of tags that users
can access. We call this a tag catalog. Components requiring a `tagCatalog`
always refer to this structure.

## Catalog Model

The tag catalog is an object carrying two arrays:

 1. An array of tags. Each tag describes one possible filter attribute.
    This array is almost certainly provided by the backend.
 2. An array of tree nodes describing the content of the add tag filter
    dialog.

We separate the functional from the presentational concern in order to allow
re-usage of the functional tag definition for consistency purposes. It also
helps us gradually introduce the new query builder without requiring a
complete rebuild of the existing tag definitions while supporting the old
query builder.

```js
{
  // functional concern
  tags: Tag[],

  // presentational concern
  tagTreeNodes: TagTreeNode[]
}
```

Many components are expecting a function `getTagCatalog` in their
configuration. In these cases they are always expecting a function
which returns an observable that resolves to a result that contains
a tag catalog. This is done to support lazy loading use cases. Example:

```js
import {just} from 'reactive-observables';

const tagCatalog = {
  tags: Tag[],

  tagTreeNodes: TagTreeNode[]
};

function getTagCatalog() {
  return just(tagCatalog);
}
```

## Tag Model

The tag model only describes the properties necessary in order to provide
basic functionality. It does not respect any presentational/UX concerns.
Refer to the tag tree model for those.

### Type Definition

```json
{
  name: String,
  type: 'STRING' | 'NUMBER' | 'BOOLEAN' | 'KEY_VALUE_PAIR',
  category: String

  canApplyToSource: Boolean,       // defaults to 'false'
  canApplyToDestination: Boolean   // defaults to 'false'
}
```

### Example

```json
{
  name: 'beacon.website.name,
  type: 'STRING',
  category: 'WEBSITE_MONITORING'
}
```

## Tag Tree Node Model

### Type Definition

```json
{
  type: 'GROUP' | 'SUB_LEVEL' | 'TAG',
  label: String,
  icon: String,         // Not supported for type=GROUP.
                        // Defaults to lib_tag for type=tag.
                        // Required for type=SUB_LEVEL.
  description: String   // Not supported for type=GROUP
  tag: String,          // Only for type=TAG
  children: TagTreeNode[]
}
```
