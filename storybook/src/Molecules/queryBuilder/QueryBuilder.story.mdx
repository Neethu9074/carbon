## Usage

```js
import {createQueryBuilder} from 'in-components/QueryBuilder';

const {QueryBuilder, isQueryValid} = createQueryBuilder({
  // see dedicated TagCatalog story for more information about the
  // TagCatalog structure.
  getTagCatalog: Observable<Result<TagCatalog>>,

  getSuggestions: {
    name: String,
    entity: undefined|'SOURCE'|'DESTINATION'
    key: ?String,
    value: ?String,
    timeConfig: TimeConfig,
    propose: 'KEYS'|'VALUES',
    tagFilterExpression: TagFilterExpressionElement
  } => Observable<Result<{
    suggestions: String[],
    totalHits: Number
  }>>
});

function getIsQueryValid([value]) {
   return isQueryValid(value)
}

function getToFormModel([tagFiltersArray]) {
   return toFormModel(tagFiltersArray)
}

function MyQueryBuilder({value, onChange}) {
  // valid is a Result<Boolean>
  const valid = useObservable(isQueryValid, [value]);
  console.log('Provided query is valid?', valid);

  // FormModel is a Result<FormModel>
  const formModel = useObservable(getToFormModel, [tagFiltersArray]);
  console.log('Tag filters array converted to query builder form model:', formModel);

  return (
    <QueryBuilder
      /*
       * See following sections to learn more about the FormModel
       * structure. This is a required parameter. It should be an
       * empty array in case the user hasn't typed in anything yet.
       */
      value={value}

      /*
       * An onChange handler which triggers whenever the query is
       * manipulated. Please note that the form model might
       * represented an invalid state, e.g. it might contains
       * unclosed brackets.
       */
      onChange={newFormModel => {…}} />
  );
}
```

## Models

The query builder makes use of four different tag filter expression
models in order to do its job:

 1. **Backend Query Model**: This is the model used in backend queries. You
    can find a detailed definition within the [backend repo](https://github.com/instana/backend/blob/644270feae74f41f871d92bfdd3aa9e01d2ff7ca/ui-model/src/main/java/com/instana/ui/model/tags/TagFilterExpressionElement.java).
 2. **Form Model**: This is the input and output for the query builder.
    This is what is being kept within a local state in
    the query builder. It is a flattened version of the tag filter
    expressions. This is done because the user must be able
    to type in invalid queries. Something that is not fully possible
    with the backend query model, e.g. single braces are not possible in the
    backend qyert model.

    The form model also contains the validation states.
 3. **Render Model**: The rendering model is created based on the form
    model. It exists to create
 4. **DOM**: The DOM is specially crafted in order to ensure
    that cursor and caret positioning, focus states and tabbing works.
    One core concern here is keyboard and mouse interaction to get as close
    to regular input field behavior as possible.

## Transformations

 1. `Form Model -> Render Model -> DOM Model -(events)-> Form Model`
 2. `Form Model -> Backend Query Model` via `in-components/QueryBuilder/transformation/backendQueryModel`
    via `toBackendQueryModel(formModel)`.

## Backend Query Model

### Only a Single Tag

```js
{
  type: 'TAG_FILTER',
  name: 'service.name',
  operator: 'EQUALS',
  value: 'shop',
  entity: 'DESTINATION'
}
```

### Multiple Tags

```js
{
  type: 'EXPRESSION',
  logicalOperator: 'OR',
  elements: [
    {
      type: 'TAG_FILTER',
      name: 'service.name',
      operator: 'EQUALS',
      value: 'shop',
      entity: 'DESTINATION'
    },
    {
      type: 'TAG_FILTER',
      name: 'service.name',
      operator: 'EQUALS',
      value: 'shipping',
      entity: 'DESTINATION'
    },
    {
      type: 'TAG_FILTER',
      name: 'service.name',
      operator: 'EQUALS',
      value: 'product',
      entity: 'SOURCE'
    }
  ]
}
```

## Render Model

### Only a Single Tag

```js
[
  // All render queries will start with a spacing.
  // This allows us to support cursor navigation at the beginning of the query.
  {
    type: 'SPACING',
    size: 'LETTER',
    leftFormModelIndex: -1,
    rightFormModelIndex: 0,
    renderModelIndex: 0
  },
  {
    type: 'TAG_FILTER',
    name: 'service.name',
    operator: 'EQUALS',
    value: 'shop',
    entity: 'DESTINATION',
    formModelIndex: 0,
    renderModelIndex: 1
    // Note: No validation/suggestion information for type=TAG
  },
  // All render queries will end with a spacing.
  // This allows us to support cursor navigation at the end of the query.
  {
    type: 'SPACING',
    size: 'LETTER',
    leftFormModelIndex: 0,
    rightFormModelIndex: 1,
    renderModelIndex: 2
  }
]
```
