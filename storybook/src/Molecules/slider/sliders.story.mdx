# Slider Types

## Restricted sliders

<Preview>
  <Story id="molecules-slider-sliders-restrictedvalues--with-numeric-scale" />
</Preview>

<Props of={RestrictedSliderRestrictedSlider} />

Restricted sliders force the user to select from a restricted number of values.
They are good to show the user the amount of choices available, and to display them in relation to each other.

- Restricted sliders can be used, when
  - the number of choices and their labels can easily be displayed along the slider axis without overlap, and
  - the options have sequential semantics (either numerical or otherwise), and
    - it is important that the user can see all available options right away, and
  - the user needs to select a value from a set of options, or
  - the user needs to select a range from the same set of options
- Restricted sliders should be avoided, when
  - the options do not have sequential meaning (eg. colors, entity types, etc.; use radio buttons or dropdown menus)
  - the number of options gets large (use input fields with autocompletion)

## Discrete sliders

<Preview>
  <Story id="molecules-slider-sliders-discretevalues--with-permanent-label" />
</Preview>

<Props of={DistinctSlider} />


Discrete sliders allow the user to select from a discrete number of values in between a min and a max value.
They are good to allow the user to easily enter a value that can only be entered in fixed steps.
Discrete sliders also work very well to manipulate a chart or other visual representation.

- Discrete sliders can be used, when
  - the number of choices is too large for a dropdown menu, and
  - the number of choices translates to a discrete numerical series with fixed steps (eg. steps of 10, 1, 0.1, 0.01 etc.), and
  - the user might want to adjust the value several times, and
  - the user needs to select a value in between in a range, or
  - the user needs to select a range within another range
- Discrete sliders should be avoided, when
  - the steps get too small for precise interaction (use an input field instead)
  - the range is too small / the steps are too wide, resulting in few options only (use a restricted slider instead)
