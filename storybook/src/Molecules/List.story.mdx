## Clickable List

You can add an `onClick` prop to each `Li` to make it clickable. Please consider using the `href` and `href$`
alternatives for improved usability, e.g. *open in new tab* support. Use `onDefaultHrefInteractionSideEffect` for
any kind of non-navigational side-effects.

<Preview>
  <Story name="Clickable List">
    <Ul>
      <Li onClick={storybookAction('click')}>Item with onClick prop</Li>
      <Li href="javascript:alert('Hello from href prop')">Item with href prop</Li>
      <Li href="javascript:alert('Hello from href prop 2!')"
          onDefaultHrefInteractionSideEffect={() => alert('Side Effect!')}>
        Item href prop and a side-effect before the link is followed. Use this to close overlays, report tracking
        information to Mixpanel etc.
      </Li>
    </Ul>
  </Story>
</Preview>

## Expandable Content

It is possible to add expandable content to lists. We currently support two kinds of expandable (sub-) content:

 1. Sub-lists with increasing levels in indentation.
 2. Free-form sub-content.

By default expandable content is only shown when the small icon is clicked. You may however change this default
behavior to *expand on row click* using the `toggleContentOnRowClick` prop.

Use the `initiallyOpen` prop to expand content by default.
