## Props

| Name                             | Type             | Required | Description                                                      | Default            |
| -------------------------------- | ---------------- | -------- | ---------------------------------------------------------------- | ------------------ |
| size                             | string OR number | optional | Size of the loading indicator. Must be a valid CSS value         | `ICON_SIZES.xxl`   |
| customStyle                      | Object           | optional | Object of style overrides                                        | `{}`               |
| customStyle.strokeWidth          | string OR number | optional | Overall stroke width                                             | 1.5                |
| customStyle.fillColor            | string           | optional | Overall fill color, can be overriden by specific fill colors     | 'transparent'      |
| customStyle.strokeColor          | string           | optional | Overall stroke color, can be overriden by specific stroke colors | `COLORS.N600Light` |
| customStyle.pillTopFillColor     | string           | optional |                                                                  |                    |
| customStyle.pillTopStrokeColor   | string           | optional |                                                                  |                    |
| customStyle.pillBodyFillColor    | string           | optional |                                                                  |                    |
| customStyle.pillBodyStrokeColor  | string           | optional |                                                                  |                    |
| customStyle.hexagonFillColor     | string           | optional |                                                                  |                    |
| customStyle.hexagonStrokeColor   | string           | optional |                                                                  |                    |
| customStyle.connectorStrokeColor | string           | optional |                                                                  |                    |
