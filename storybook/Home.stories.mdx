# Welcome

Welcome to the **ui-client** storybook documentation and playground.

## Purpose

The main purpose it to show a single ui components separated without the whole product context and without server-connection.

This storybook will be build and updated based on **develop** branch.

## Structure

The folder structure in the story tree follows the organisation of our packages. You can find these stories inside the specific sub folder below `packages`.
