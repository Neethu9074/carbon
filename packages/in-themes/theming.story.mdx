## Introduction

Theming is something which can be done in many differnt ways. You can control it via css variables, react context, passing down the current theme prop and react on it and so on.
The hook, which is documented here introduces a way that the theme can be changed with the react context. The advantage is that one can partially change themes on compoents to get full control.
The only thing which changes on themed components is the style, so this hook will only work with the style definition. Only a very small amount of code change is required so one
can easily change a component to support themes mostly without messing aroung with different style names etc.

## Imports

Chaning the theme via react context

```js
import { light } from '@instana/components';

import LocallyChangedTheme from 'in-themes/LocallyChangedTheme';
```

Consuming the theme via react hook

```js
import useThemedLocals from 'in-hooks/useThemedLocals';
```

## Changing the theme

This is quite straight forward. One needs to wrap the part of the UI inside a `<LocallyChangedTheme />` wrapper and the theme context will be
available for all children mounted inside this context.

```js
import React from 'react';

import LocallyChangedTheme from 'in-themes/LocallyChangedTheme';

import { dark } from '@instana/components';

function MyComponent() {
  return (
    <LocallyChangedTheme theme={dark}>
      <ThemedComponent />
    </LocallyChangedTheme>
  );
}
```

## Consuming the theme and theming a component

To avoid thouching all usages of locals or messing around with classnames etc., the only thing which needs to be done on the code side
is to import the hook and insert the one line inside the component `const locals = useThemedLocals(styleDefs)`. All the usages of locals.whatEver
can stay. The hook takes care that the right style definition is used.

```js
import React from 'react';

import useThemedLocals from 'in-hooks/useThemedLocals';

import styleDefs from './style.mless';

function ThemedComponent() {
  const locals = useThemedLocals(styleDefs);
  return <div className={locals.wrapper}>Theme Component</div>;
}
```
