# Dialog to Modal migration

This is a guide on how to migrate an Insatana Dialog component to a Carbon Modal.

## Useful Links

[Sample PR of a migrated Dialog](https://github.ibm.com/instana/ui-client/pull/17704)

[Carbon Modal Storybook](https://react.carbondesignsystem.com/?path=/docs/components-modal--overview)

[Carbon Design System Modal Usage](https://carbondesignsystem.com/components/modal/usage/)

## Migration steps

#### 1. Change import from Dialog to CarbonModal from '@instana/components'

#### 2. Update props using mapping table below

#### 3. Use `carbonModalEnabled` featureFlag if not changing to CarbonModal 100% of the time.

\*See [sample PR](https://github.ibm.com/instana/ui-client/pull/17704) for an example.

## Component mappings

See [Carbon Design System documentation here](https://carbondesignsystem.com/components/modal/usage/#modal-variants) for all the different Carbon Modal Variants to choose the best Modal for your use case.

## Migration tips and best practices

- Sizing: Use carbon size prop rather than custom sizes. [See carbon Modal sizing docs](https://carbondesignsystem.com/components/modal/usage/#sizing)

- Loading: Use loading props rather than custom loading components. [See modal loading docs](https://carbondesignsystem.com/components/modal/usage/#loading)

- For best practices with stacking Modals, please look at the Stacking tearsheets docs in the [IBM Products library](https://carbon-for-ibm-products.netlify.app/?path=/story/ibm-products-components-tearsheet--stacked-mixed-sizes)

  - To override z-index of carbon modals and make stacking modals possible, add `z-index: var(--ids-z-index-option-dialog);` as a custom style.

- IBM Products supports create flows, tearsheets and multi-step modals that use Carbon Patterns and save time in implementation.
  \*Note IBM Products is not yet a part of ui-client.
