## Floating Action Button

We use the Floating Action Button for primary actions that apply to a page / entity. A good example is “Create SLI” or “Add Alert”.

# Placement

## Floating Action Button Placement
<EmbeddedImage floatRight src={layout} />

- Floating Action Buttons are aligned to the bottom right with a 24 dp margin from the viewport boundaries
- Any scrollable content needs an additional 96 dp padding at the bottom to allow scrolling past the floating action button

<Clearfix />

<EmbeddedImage floatRight src={alignment} />

- A maximum of 2 Extended Floating Action Buttons and 1 Icon-only Floating Action Button can  be displayed at the same time
- The right most Floating Action Button is the primary action for the current view

<Clearfix />

<EmbeddedImage floatRight src={placement} />

- For non-scrollable content (eg. maps, canvas elements etc.) additional controls / interaction elements should not be placed in the area reserved for Floating Action Buttons. See image to the right for designated map control areas.
