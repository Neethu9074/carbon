# Customized Carbon TimePicker
 A component that provides an Instana wrapper around the Carbon components for picking time. Using this customized
 TimePicker,
 rather than the Carbon native components directly, allows for a consistent usage of time picking across Instana.
 Time format is automatically checked to match the pattern ``/^([01]\d|2[0-3]):?([0-5]\d)$/`` or ```HH:mm```.

 At this time only a 24 hour clock is supported.
