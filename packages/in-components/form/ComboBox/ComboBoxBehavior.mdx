## ComboBoxBehavior

`ComboBoxBehavior` implements logic which turns any HTML element into a clickable element that triggers
an `Overlay` in which items can be selected. `ComboBoxBehavior` can be used as a primitive to implement
higher-level components or it can directly be used in non-reusable code to implement features.
