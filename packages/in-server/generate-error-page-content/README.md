# Generate error page templates

Error page templates are generated by this small vite app that does the **pre-rendering** of
the error page content into a files that are used by [Handlebars](https://handlebarsjs.com) in the in-server
component to serve error pages to the browser.

The pre-render allows Carbon react components to be used without including SSR in the server or requiring the Carbon react library or pre-reqs to be loaded on the client side.

## Styling and fonts

The style sheets and font files are generated and located in the `dist` directory

## Generating the templates

In the root folder of ui-client repo,
```shell
run `yarn generate-error-pages`
```

Or
in the folder `packages/in-server` ,  run

```shell
yarn run build:staticpages
```

Templates and stylesheets are copied to the in-server directory.
