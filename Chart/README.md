# Chart

## Option format
```javascript
{
  container: <HTML dom element in which the canvas will be placed>,
  type: 'stackedArea',
  width: <chart width in pixels>,
  height: <chart height in pixels>,
  margins: {
    top: 20,
    right: 20,
    bottom: 20,
    left: 20
  }
  seriesConfig: [
    // TODO
  ],
  windowSize: <total number of milliseconds to show in the graph>
}
```
